# TuristeaYa

Proyecto integrado con aplicación Expo, frontend web y backend FastAPI.

Consulta `outputs/CONTEXTO_TURISTEAYA.md` y `outputs/REVISION_SISTEMA.md` para configuración, pruebas y pendientes.

Para Expo Go ejecuta `./outputs/INICIAR_EXPO_GO.ps1`. Para la web y backend local ejecuta `./outputs/INICIAR_LOCAL.ps1 -WebPort 4174`, después de configurar el entorno Python y `.env` del backend.
